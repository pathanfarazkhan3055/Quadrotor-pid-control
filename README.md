# PID Control of Quadrotor Altitude Stabilization Under Wind Gust Disturbances

## Overview
Developed and simulated a PID-based altitude stabilization system for a quadrotor UAV using MATLAB/Simulink.

## Tools Used
- MATLAB
- Simulink
- Python

## Control Techniques
- PID Controller
- Root Locus
- Routh-Hurwitz Criterion
- Bode Analysis

## Key Results
- Wind Disturbances: 0–15 m/s
- Rise Time: 1.4 s
- Settling Time: 2.1 s
- Overshoot: 0.3 m
- Phase Margin: 58°
- Gain Margin: 11 dB
